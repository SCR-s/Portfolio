# Surya Chandra Regmi — Portfolio Website

A responsive, single-page personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `portfolio`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The public URL will be shown in the Pages settings.
